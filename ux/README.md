# UX 改稿区

界面实现目前全在上一级的 `GrokRecent.ps1` 里（WinForms，不适合直接改像素）。

**请只在这个 `ux` 文件夹里改。** 写完或丢图之后跟我说「整合 UX」，我再改启动器。

## 你怎么用

1. 把说明写进 `NOTES.md`（按页：仪表盘 / 项目 / 监视）
2. 截图、线框、参考图丢进 `mockups/`
3. 可选：单页 HTML 草稿也可以放 `mockups/`（例如 `dashboard.html`）

不要改 `GrokRecent.ps1`，避免和程序逻辑搅在一起。

## 三页对应

| 页 | 启动器里 | 建议你写 |
|---|---|---|
| 仪表盘 | 打开后的首页 | 总量、趋势、排行、最近会话 |
| 项目 | 顶部「项目」 | 列表、选中、继续/新建/指定文件夹 |
| 监视 | 顶部「监视」 | 窗口列表、展开详情、打开/结束 |

## 我会怎么合

只按你写进 `NOTES.md` 和 `mockups/` 的内容改启动器，不会把监控站或其他项目扯进来。
