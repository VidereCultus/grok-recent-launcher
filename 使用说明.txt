Grok 最近项目启动器
====================

解决的问题
  开过多个 Grok 窗口、关掉之后，不必再一个一个翻到对应文件夹。

怎么用
  1. 双击「【点我】创建桌面图标.bat」，桌面会多一个「Grok 最近项目」
  2. 以后双击那个图标
  3. 勾选一个或多个项目 → 点「续上」（或直接双击）
  4. Windows Terminal 会按这些目录打开标签，并执行 grok -c

按钮
  启动会话走代理
           项目页下方可勾选，并填写地址（默认 http://127.0.0.1:7890，可改端口）
           点「检测」：读系统代理和 FlClash 的 mixed-port，再探测本机常见端口
           当前地址还能用就不会改；连不上会自动填上正在用的那个，并提醒重开 Grok
           打开启动器时也会静默检测一次（地址没变就不弹条）
           绿色「已连通」才能顺利启动；连不上会在列表上方出红条，不弹系统对话框
           只影响本启动器拉起的 Grok，不写系统环境变量
           取消勾选则直连（国内通常连不上）
  继续最近会话 / 新建会话 / 打开终端 / 资源管理器
           只作用于列表里黄色选中的那一行，不是资源管理器里点的文件夹
  指定文件夹
           弹出文件夹窗口。在列表里点一个文件夹，再点「选择文件夹」，
           Grok 就在那个文件夹里新开
  终端     只打开终端，停在该目录
  刷新     重新读取本机 ~/.grok/sessions
  关于     隐私说明与版本
  右键「打开文件夹」仍是用资源管理器打开

使用记录
  左侧进入「使用记录」。页顶可切「总览 / 分析 / 请求明细 / 价格统计」
  可按今天 / 近 7 天 / 近 30 天 / 全部，以及模型筛选
  上面是趋势图和 Token 构成，下面是最近轮次，双击一行可续上那个项目
  只读 usage.json 的计数，不读对话全文

外观和关闭
  标题栏「浅色 / 深色」可以换主题，选择会记住
  点关闭时可选「缩小到后台」或「退出程序」，也可以记住
  缩到后台后，双击托盘图标打开；托盘右键可以退出，或让下次关闭再问一次

仪表盘（打开后的首页）
  最大的数字是总 Token（百万 M）。旁边小字是输入/输出占比。
  趋势图可悬停看当天总量、输入、输出和较昨日变化。
  左：项目用量排行（条越长占比越高，点它打开该项目）
  右：最近项目。数字是同时恢复几个，按钮会写成「恢复 5 个项目」
  时间：今天 / 近 7 天 / 近 30 天 / 全部
  数据来自本机 usage.json，不读对话全文

监视页
  点标题栏「监视」查看当前多开的 Grok 窗口
  点开一行展开：正在执行的工具、最近动作、Token、Context
  折叠行会显示「正在执行 xxx」或「上一轮：…」
  刚创建：金色加号
  进行中：转圈
  刚完成：绿勾（窗口还开着）
  空闲：灰圈（停在提示符）
  底下细条是上下文占用，不是上传进度

其它
  点 ★ 可以把常用项目钉在最上面
  支持搜索、多选、右键菜单
  置顶名单保存在 %APPDATA%\GrokRecentLauncher\，不会进 Git

隐私
  只读本机会话摘要（目录、标题、时间）。
  不读取对话全文，不联网，不上传。
