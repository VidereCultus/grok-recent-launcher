Grok 最近项目启动器
====================

解决的问题
  开过多个 Grok 窗口、关掉之后，不必再一个一个翻到对应文件夹。

怎么用
  1. 双击「【点我】创建桌面图标.bat」，桌面会多一个「Grok 最近项目」
  2. 以后双击那个图标
  3. 勾选一个或多个项目 → 点「续上」（或直接双击）
  4. Windows Terminal 会按这些目录打开标签，并执行 grok -c

按钮
  续上     在列表选中的目录打开 Grok，并继续上次会话
  新开     在列表选中的目录打开 Grok，新会话
  文件夹   弹出目录选择框，选完后在该路径新开 Grok
  终端     只打开终端，停在该目录
  刷新     重新读取本机 ~/.grok/sessions
  关于     隐私说明与版本
  右键「打开文件夹」仍是用资源管理器打开

仪表盘（打开后的首页）
  最大的数字是总 Token（百万 M）。旁边小字是输入/输出占比。
  趋势图可悬停看当天总量、输入、输出和较昨日变化。
  左：项目用量排行（条越长占比越高，点它打开该项目）
  右：最近项目。数字是同时恢复几个，按钮会写成「恢复 5 个项目」
  时间：今天 / 近 7 天 / 近 30 天 / 全部
  数据来自本机 usage.json，不读对话全文

监视页
  点标题栏「监视」查看当前多开的 Grok 窗口
  刚创建：金色加号
  进行中：转圈
  刚完成：绿勾（窗口还开着）
  空闲：灰圈（停在提示符）
  底下细条是上下文占用，不是上传进度

其它
  点 ★ 可以把常用项目钉在最上面
  支持搜索、多选、右键菜单
  置顶名单保存在 %APPDATA%\GrokRecentLauncher\，不会进 Git

隐私
  只读本机会话摘要（目录、标题、时间）。
  不读取对话全文，不联网，不上传。
